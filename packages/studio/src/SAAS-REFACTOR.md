# SaaS 模式功能重构方案

## 许可证红线
禁止：让用户获取 Remotion 工程代码、注入自己的代码、使用自己的 AI 智能体改代码。

## 重构策略：从"代码操作"到"模板 + 参数"

| 原功能 | 原实现 | SaaS 重构版 | 状态 |
|--------|--------|-------------|------|
| 下载项目 | 导出完整工程 zip（含 .tsx 代码） | 导出渲染成品视频 + 模板参数 JSON（不含代码） | ✅ 已实现 |
| Generate with agent | 用户驱动 AI 写代码到工程 | 服务端 AI 根据提示词生成**参数预设**（props JSON），不生成代码 | 🔄 本方案实现 |
| Ask AI | 把代码上下文发给 AI 智能体 | 智能助手：仅回答模板使用问题，返回操作建议（如"把时长调到 150 帧"），由前端参数 API 执行 | 🔄 本方案实现 |
| Install package | npm 安装任意包（注入代码） | 官方素材中心：服务端审核过的素材包，以参数/资源形式接入 | 🔄 本方案实现 |
| 元素库 | 从第三方 URL 拉代码安装 | 官方元素中心：服务端托管的注册元素，仅暴露参数 | 🔄 本方案实现 |
| Fix computed value / Pre-compose / Wrap 重构 | 原生代码重构 | 用参数层操作替代：重置默认值、组合为分组、调整层级（纯 UI 操作） | 🔄 本方案实现 |

## 技术实现
- 开关：window.remotion_saasMode = true 或 ?saas=1（见 saas-mode.ts）
- 所有重构版功能挂在 saas-feature 目录下，替换原入口
